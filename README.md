# 工位失控 · 第三人称办公室练习场

用 Godot 4 打开此文件夹中的 `project.godot`，运行项目即可查看。方向键或 WASD 移动角色；直接移动鼠标可旋转镜头；滚轮调整镜头距离；按 R 将镜头回正到角色面向。运行时鼠标会锁定在游戏窗口内，按 Esc 释放，点击游戏画面重新锁定。角色移动只会让镜头跟随平移。

左键扔文件夹，命中前方训练稻草人会显示累计命中次数；右键扔咖啡，落地后会留下短暂的咖啡滩。所有攻击都沿角色当前面朝方向释放，释放时不会改变角色朝向或镜头方向。

Shift 向角色前方短闪现，空格跳跃。Q 第一次举伞冲刺，再按 Q 挑飞附近的稻草人；冲刺结束会立即停步。F 踢击：地面目标被踢远，浮空目标受到更强的空中追踢。E 用椅子砸前方目标，砸中浮空目标会将其击落。可以试试“Q 冲刺 → Q 挑飞 → F 追踢”，或者“Q 冲刺 → Q 挑飞 → E 空中椅砸”。

竞技场为 110×80，面积超过旧场地的 11 倍，有围墙、四组办公掩体、会议桌、茶水区和箱子。场内有 16 个训练稻草人，各有 100 HP；攻击后显示剩余血量，归零时倒地，约 5 秒后复活。打开项目即可进入单人练习场。

打击反馈包含挥动音、命中音、短暂出手前摇、命中停顿、镜头轻震、受击闪色和撞击碎片。雨伞冲刺还会留下短暂残影。镜头默认距离为 6 米，可用滚轮在 3.8 到 8 米之间调整。音效是本项目用程序生成的占位音，可以后续替换。

场景包含简易办公室、工位、会议区、茶水间、文件柜、植物及一只由基础 3D 形体组成的小狗角色。所有模型都在 `office_demo.tscn` 中，可以直接在编辑器里选中、移动和换材质。移动逻辑在 `player.gd`。

这是验证第三人称视角、移动和基础连招手感的灰盒原型。玩家对战留待后续制作。
